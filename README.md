# 42 Piscine — C & Shell Exercises

This repository contains my work and solutions developed during the **42 Piscine**, an intensive programming experience focused on building strong foundations in **C programming, algorithms, problem-solving, and Unix command-line environments**.

Throughout the Piscine, I worked through a progressive series of exercises covering fundamental programming concepts and gradually introducing more advanced techniques. The exercises emphasize not only writing functional code, but also understanding how programs work at a lower level and developing efficient problem-solving habits.

## 📚 Topics Covered

* **C Programming Fundamentals**

  * Variables, data types, operators, and control structures
  * Functions and modular programming
  * Loops and conditional statements
  * Character and string manipulation

* **Pointers & Memory**

  * Pointer manipulation
  * Memory addresses
  * Arrays and strings
  * Dynamic memory allocation

* **Algorithms & Problem Solving**

  * Mathematical operations
  * Number conversions
  * Sorting and searching concepts
  * Recursive programming
  * Algorithmic thinking

* **Advanced C Concepts**

  * Structures
  * Function pointers
  * Header files
  * Command-line arguments
  * Dynamic memory management

* **Unix & Shell**

  * Bash commands
  * File and directory manipulation
  * Permissions
  * Environment and command-line tools
  * Shell scripting

## 🎯 Objectives

The main objectives of this Piscine were to:

* Build a solid foundation in **C programming**
* Improve logical and algorithmic problem-solving skills
* Understand pointers, memory, and low-level programming concepts
* Become comfortable working in a **Unix/Linux environment**
* Develop the ability to learn independently and solve unfamiliar problems
* Practice writing structured and maintainable code
* Become familiar with the collaborative and demanding learning environment of **42**

## 📌 About the 42 Piscine

The **42 Piscine** is an intensive selection and learning program designed around peer learning, practical exercises, and self-directed problem solving. Instead of relying primarily on traditional lectures, participants learn by researching, experimenting, debugging, and collaborating with other students.

This repository represents my progression through the C and Shell exercises completed during this experience.
